# Roadmap: «Мандариновый забег»

Учебный проект на HTML, CSS и JavaScript. Каждый пункт рассчитан на один небольшой осмысленный commit. Функции добавляются последовательно: от статичной сцены к полноценной игре.

## Этап 1. Основа и первый прототип

- [x] **Day 1 — Стартовая сцена.** Создать HTML-каркас, стили площадки и первый интерактивный клик-счётчик без прыжка.
- [x] **Day 2 — Отдельные сущности.** Подготовить понятную структуру игрового поля для Чебурашки и мандаринов.
- [x] **Day 3 — CSS-спрайт Чебурашки.** Заменить emoji на простую CSS-иллюстрацию персонажа.
- [x] **Day 4 — CSS-спрайт мандарина.** Сделать одно аккуратное препятствие средствами CSS.
- [x] **Day 5 — Кнопка старта.** Добавить состояния «готов», «игра идёт» и «завершено».
- [ ] **Day 6 — Первый прыжок.** По клику запускать CSS-анимацию прыжка.
- [ ] **Day 7 — Пауза.** Добавить возможность поставить игру на паузу.

## Этап 2. Движение и столкновения

- [ ] **Day 8 — Движение мандарина.** Запустить одно препятствие слева направо.
- [ ] **Day 9 — Игровой цикл.** Перевести движение на `requestAnimationFrame`.
- [ ] **Day 10 — Сброс игры.** Реализовать кнопку повторного запуска.
- [ ] **Day 11 — Координаты.** Хранить позиции Чебурашки и мандарина в JavaScript.
- [ ] **Day 12 — Гравитация.** Добавить вертикальную скорость и естественное падение.
- [ ] **Day 13 — Ограничение пола.** Не позволять персонажу проваливаться сквозь землю.
- [ ] **Day 14 — Проверка столкновения.** Остановить игру при контакте с мандарином.

## Этап 3. Игровые правила

- [ ] **Day 15 — Жизни.** Добавить три попытки.
- [ ] **Day 16 — Счёт за прыжок.** Начислять очки за успешно пройденное препятствие.
- [ ] **Day 17 — Экран результата.** Показать итоговый счёт после проигрыша.
- [ ] **Day 18 — Лучший результат.** Сохранять рекорд в `localStorage`.
- [ ] **Day 19 — Рестарт клавишей.** Поддержать `Space` для перезапуска.
- [ ] **Day 20 — Понятные статусы.** Улучшить сообщения и доступные состояния интерфейса.
- [ ] **Day 21 — Неделя правил.** Почистить код игры и вынести константы.

## Этап 4. Сложность

- [ ] **Day 22 — Ускорение.** Постепенно увеличивать скорость мандаринов.
- [ ] **Day 23 — Случайный интервал.** Менять расстояние между препятствиями.
- [ ] **Day 24 — Несколько мандаринов.** Добавить последовательность препятствий.
- [ ] **Day 25 — Разная высота.** Ввести мандарины на разных уровнях.
- [ ] **Day 26 — Бонусная мандаринка.** Добавить собираемый объект.
- [ ] **Day 27 — Бонусные очки.** Начислять очки за сбор бонуса.
- [ ] **Day 28 — Звуковой сигнал.** Добавить короткий звук прыжка через Web Audio API.
